# JOJO的胶囊 🧺

一个用来回答「我到底买过什么」的微信小程序。

不是记账工具——钱只是物品的一个可选属性。它记录的是物品本身：
什么时候来的、从哪来的、陪伴了多少天、每天摊下来多少钱、
用完了还买不买。目标是帮自己俭省地生活，搬家时不崩溃。

## 功能

- 📷 十秒录入：拍照 + 名称，其他全部可选，绝不制造记录压力
- 🔍 买前搜一下：防止重复购买同款
- 🏷️ 分类 + 自由标签：预设商超式分类，支持自定义
- 🎁 来源记录:购买平台或「谁送的」，人情账比金钱账有意思
- 🎂 物品生日：每件物品显示「已陪伴 N 天」
- 💰 每天成本：填了价格自动计算，越用越便宜，鼓励用旧不买新
- 🔄 状态流转：在用 / 用完 / 闲置 / 送出 / 丢弃
- 🤔 灵魂拷问:标记「用完」时询问「还买吗」，沉淀回购决策

## 技术栈

- 微信小程序原生开发（WXML / WXSS / JS）
- 微信云开发（云数据库 + 云存储），无自建后端
- 图片自动压缩上传

## 设计

「燕麦拿铁」配色：奶油米白打底，冷淡骨相，全场唯一主色为燕麦咖。
